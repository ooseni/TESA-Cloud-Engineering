Private S3 site behind CloudFront

Served over HTTPS by Amazon CloudFront from an Amazon S3 bucket that the internet cannot read directly.

How this page reached you:

  1. your browser connected to the nearest CloudFront edge location over HTTPS;
  2. CloudFront signed a request to the bucket with Origin Access Control;
  3. the bucket policy accepts requests from this distribution only, and Block Public Access refuses everyone else;
  4. CloudFront added security headers and cached the page at the edge.

Everything here, from the bucket to the headers, is built by Terraform.

Part of TESA-Cloud-Engineering, module 10.
