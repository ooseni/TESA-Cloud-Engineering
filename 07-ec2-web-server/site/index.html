Static site on Amazon EC2

Served by Apache on Ubuntu 24.04, published by a deployment script that runs as EC2 user data.

At first boot the script:

  1. frees port 80 if another web server holds it, and disables that server so it stays stopped;
  2. installs Apache with apt-get;
  3. publishes this page read-only, owned by root;
  4. checks Apache's configuration, then starts it;
  5. confirms this page is being served before reporting success.

Part of TESA-Cloud-Engineering, module 07.
